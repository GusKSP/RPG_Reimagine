RPG Reimagine 1.0

Sistema web desenvolvido para organização e gerenciamento de mesas de RPG, campanhas, mundos e elementos do jogo. O objetivo do projeto é facilitar a criação e administração de universos de RPG de forma centralizada, permitindo que mestres e jogadores tenham mais controle sobre suas sessões e estruturas de jogo.

Sobre o projeto

O RPG Reimagine foi construído para resolver problemas comuns em mesas de RPG online e presenciais, como desorganização de campanhas, dificuldade de controle de usuários e falta de estrutura para armazenar informações do mundo criado.

Com ele, é possível criar e gerenciar campanhas, associar jogadores, estruturar mundos personalizados e trabalhar com elementos dinâmicos dentro das mesas.

Funcionalidades

Usuários
- Cadastro e gerenciamento de usuários
- Associação de usuários a campanhas e mesas
- Controle de participação em diferentes mundos

Campanhas
- Criação de campanhas com código de acesso
- Entrada de usuários em campanhas via código
- Integração com mesas e mundos do sistema

Mesas e Mundos
- Criação de mesas de RPG
- Organização de mundos personalizados
- Relacionamento entre mesas, campanhas e usuários

Elementos do RPG
- Registro de elementos como habilidades, itens ou entidades
- Associação com mesas e campanhas
- Estrutura dinâmica para expansão do sistema

Dashboard
- Visualização de dados quantificáveis do sistema
- Quantidade de elementos por mesa
- Informações gerais para análise e aprimoramento da aplicação

Arquitetura

O projeto segue o padrão MVC (Model, View, Controller), separado de forma a manter organização e escalabilidade.

Backend
- Node.js
- Express
- API Web-data-viz

Frontend
- HTML, CSS e JavaScript puro
- Uso de fetch para comunicação com a API
- Integração com modais e telas dinâmicas

Melhorias futuras

- Criação de Personagens
- Mais Informações Para a Dashboard e Acesso de Interesse Ao Público
- Notificações em tempo real
- Administração Constante
- Disponibilidade para Web

Objetivo

O objetivo do RPG Reimagine é se tornar uma plataforma completa para gerenciamento de RPG, permitindo que os seus usuários consigam criar próprias campanhas para jogarem com seus colegas.
